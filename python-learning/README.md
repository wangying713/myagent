# Python 语法学习

这个文件夹专门放 Python 语言和标准库的小练习，与 `agent-learning/` 的
Agent 开发课程分开。

## 运行

在仓库根目录运行：

```bash
python3 python-learning/with_statement.py
```

练习只使用 Python 标准库，不需要 API key，不调用模型，也不产生
OpenObserve 数据。

## 当前内容

- [`with_statement.py`](with_statement.py)：`with`、`as`、同时读写两个文件、
  异常时的清理，以及 SQLite 连接的事务管理。
