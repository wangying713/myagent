# OpenObserve 观测组件

本包提供私有 OpenTelemetry Traces、Agent 运行观测和展示正文脱敏。由应用入口显式传入配置，不读取环境、不修改全局 provider，也不执行 Agent 业务。

| 文件 | 职责 |
| --- | --- |
| `client.go` | 客户端构造、追踪器、刷新、关闭和入口所需的 provider 与采集上限 |
| `config.go` | 组件配置及构造所需的最低校验 |
| `exporter.go` | 私有 provider、OTLP/HTTP 导出、批量上报和失败提示 |
| `run.go` | 单次业务运行的观测资源、模型配置快照、统计和结束状态 |
| `preview.go` | 领域输入与结果到观测 JSON 的白名单转换 |
| `content.go` | 正文采集、脱敏、限长和 OpenObserve 预览属性 |

测试按相同职责放在对应的 `*_test.go` 中。

## 配置与生命周期

启动配置、默认值和环境解析由 `apps/config` 负责。`ServiceName` 标识服务，`TracerName` 标识创建业务与模型 span 的追踪器；两者均须显式提供。启动时通过 `TELEMETRY_TRACER_NAME` 设置追踪器名称，默认仍为 `go-demos`。正文上限不得小于 `MinContentMaxChars`。

应用创建一个可并发共享的 `Client`。调用方直接使用只读的 `Client.Tracer.Start` 创建 span，并显式传入 span 类型和属性；本包不再转发 SDK 的 `Start` 方法。客户端只保留运行所需的资源和正文设置，不长期保存整份启动配置；是否启用观测由私有 provider 是否存在决定。启用观测时，客户端接管注入的导出器；未注入时创建 OTLP/HTTP 导出器。关闭观测时不创建上报资源，仍提供展示脱敏。应用应先结束请求，再使用有期限的上下文调用 `Close`；`Flush` 只刷新队列，不关闭客户端。上报失败只输出一次固定提示，不输出底层错误正文，也不改变业务结果。

## 运行与正文

应用通过 `StartRun` 获取派生上下文和运行观测对象，将上下文传入业务，并在业务完成后调用 `Run.End`，传入完整或部分结果及最终错误。模型配置在开始时复制，后续修改不会影响本次记录。上下文的父链路、取消及截止时间继续向下传递。

无结果时只记录结束状态；有结果且 span 正在记录时保留调用次数和 token 统计。只有开启正文采集且 span 正在记录时才组装和编码运行预览；关闭观测或正文采集时 `ContentLimit` 为零，`Payload` 不再处理正文。工具调用作为结果中的步骤保存，不创建独立工具 span。

预览类型属于观测格式，不作为领域协议或 HTTP 响应使用。转换保留现有字段名、毫秒单位、空数组和 null；有效 JSON 保留层级与数值精度，无效或截断片段按文本记录。脱敏和限长只生成展示副本，不改写领域输入、历史消息和调用记录。

## 离线验证

在仓库根目录运行：

```sh
./scripts/go vet ./...
./scripts/go test ./...
./scripts/go test -race ./...
```

本包测试使用内存导出器和内存 HTTP 传输，不监听端口、不连接外部服务，也不读取真实密钥。全仓 HTTP 集成测试使用本机临时端口。
