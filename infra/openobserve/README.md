# OpenObserve 观测组件

本包提供私有 OpenTelemetry Traces、Agent 运行观测和展示正文脱敏。由应用入口显式传入配置，不读取环境、不修改全局 provider，也不执行 Agent 业务。

| 文件 | 职责 |
| --- | --- |
| `client.go` | 客户端配置与构造、OTLP 导出、资源释放和 span 正文写入 |
| `trace.go` | 单次运行观测、输入输出预览类型及转换 |
| `redaction.go` | 脱敏词整理、文本与 JSON 脱敏、正文限长 |
| `redaction_stream.go` | 增量脱敏阶段组合及固定密钥的短前缀匹配 |
| `redaction_auth.go` | 鉴权前缀和值的增量状态处理 |
| `redaction_json.go` | 敏感 JSON 字段的增量状态处理 |
| `redaction_sse.go` | 按显式指定的事件字段路径处理 SSE 展示副本 |

测试按相同职责放在对应的 `*_test.go` 中。

## 配置与生命周期

启动配置、默认值和环境解析由 `apps/config` 负责。`ServiceName` 标识服务，`TracerName` 标识创建业务、模型与工具 span 的追踪器；两者均须显式提供。启动时通过 `TELEMETRY_TRACER_NAME` 设置追踪器名称，默认仍为 `go-demos`。正文上限不得小于 `MinContentMaxChars`。

应用创建一个可并发共享的 `Client`。调用方直接使用只读的 `Client.Tracer.Start` 创建 span，并显式传入 span 类型和属性；本包不再转发 SDK 的 `Start` 方法。客户端只保留运行所需的资源和正文设置，不长期保存整份启动配置；调用方通过 `Client.Provider != nil` 判断是否启用观测，不表示上报成功。`Provider` 由构造函数创建，调用方不修改该字段，生命周期仍由客户端管理。启用观测时，客户端接管注入的导出器；未注入时创建 OTLP/HTTP 导出器。关闭观测时不创建上报资源，仍提供展示脱敏。应用应先结束请求，再使用有期限的上下文调用 `Close`；需要提前刷新时，在 `Provider` 非 nil 的情况下直接调用 `Provider.ForceFlush(ctx)`，不关闭客户端。上报失败只输出一次固定提示，不输出底层错误正文，也不改变业务结果。

## 运行与正文

应用通过 `StartTrace(ctx, spanName, operation)` 显式传入 span 名称和业务操作，获取派生上下文和 `Trace` 观测对象，将上下文传入业务，并在业务完成后直接调用 `Trace.End`，传入完整或部分结果及最终错误。`End` 统一处理结果展示字段的脱敏与限长，然后记录并结束 span，应用层不再包装结束方法。HTTP 应用层统一传入自己定义的 `agent.run`，观测组件不内置业务 span 名称。模型信息由实际模型调用的 span 记录，运行输入预览不再附带模型配置快照。上下文的父链路、取消及截止时间继续向下传递。

无结果时只记录结束状态；有结果且 span 正在记录时保留调用次数和 token 统计。只有开启正文采集且 span 正在记录时才组装和编码运行预览；有效正文采集上限在构造时计算一次；关闭观测或正文采集时只读字段 `ContentLimit` 为零，`Payload` 不再处理正文。工具调用既保存为运行结果中的步骤，也由应用层 `app/tool_trace.go` 在实际执行期间创建独立子 span；工具节点的输入、输出复用本包的正文预览、脱敏和限长；输入保留 `id/type/name/arguments`，属性沿用 `app.tool.name`、`app.tool.call.id` 和业务拒绝时的 `app.tool.error`。关闭正文采集时仍保留工具节点、名称和状态；关闭观测时直接执行原始工具，不创建节点。

预览类型属于观测格式，不作为领域协议或 HTTP 响应使用。转换保留现有字段名、毫秒单位、空数组和 null；有效 JSON 保留层级与数值精度，无效或截断片段按文本记录。`Trace.End` 就地更新结果的展示字段，调用记录先复制切片再脱敏，不覆盖其他引用持有的原始记录；实际执行输入和模型历史保持原样。回答仅脱敏，请求、响应正文同时限长。关闭观测或正文采集时仍处理结果展示字段。

文本流在应用边界使用独立的 `TextRedactor`，按配置密钥、鉴权文本、敏感 JSON 字段的顺序增量处理。普通连续文本实时输出，只暂存可能构成密钥或协议标记的短前缀；敏感值一旦确认便输出遮盖标记，后续只记录结束符和转义状态。待定鉴权前缀达到 256 字节时保守遮盖，避免异常长的空白占用缓存。结束时顺序刷新各阶段，消费者取消后不再写出。

`Safe` 只处理普通文本和 JSON，不根据正文猜测 SSE。模型流的调用处通过 `SafeSSE(raw, "choices.0.delta.content")` 显式指定协议和文本路径，应用层同样显式处理流式执行记录。该方法不内置模型或 HTTP 响应结构；展示副本可以调整相邻事件中的文本分布，实际模型响应保持原样。SSE 片段无法完整解码时遮盖整份预览，避免损坏或截断的事件暴露敏感值。

## 离线验证

在仓库根目录运行：

```sh
./scripts/go vet ./...
./scripts/go test ./...
./scripts/go test -race ./...
```

本包测试使用内存导出器和内存 HTTP 传输，不监听端口、不连接外部服务，也不读取真实密钥。全仓 HTTP 集成测试使用本机临时端口。
