日期：2026-10-05。本轮检查覆盖课程与代码对应关系、示例独立运行、底层调用协议、观测完整性、结果校验及新加入的状态与恢复逻辑。

2026-10-09 更新：删除纯本地恢复与模拟重试 demo，去掉评估的假模型模式，并同步课程入口、运行命令与测试引用。当前课程共 10 个围绕真实模型交互的 demo。以下问题表保留为 2026-10-05 的历史记录。

## 发现的问题及处理

| 发现 | 处理 | 验证证据 |
|---|---|---|
| 原版中高级材料主要是扩展任务，没有完整 demo，不能算课程全部落地 | 新增 7 个 demo，整理为初级 3、中级 5、高级 4；每级提供运行与通过标准 | 全部脚本有对应课程卡片，真实或离线运行通过 |
| 课程已分级，但 demo 文件名仍是旧名称，目录里看不出级别 | 12 个入口脚本统一改为 `beginner_`、`intermediate_`、`advanced_` 前缀并编号；同步更新导入、运行命令和文档 | 25 项离线测试通过，旧名称引用检查无残留 |
| 真实验收只检查有响应、JSON 类型合法或出现工具节点，可能放过错误业务结果 | 检查具体答案、订单值、工具实际结果、引用与恢复后的状态；移除会被 `python -O` 跳过的 assert | 分级真实验收与四个计算评估用例通过 |
| 验收等待条件未包含全部工具节点，存在提前检查不完整 trace 的可能 | 底层累计模型与工具次数，按两者之和加根节点核对全部记录 | 本轮资料 Agent 返回两个搜索，实际 5 个节点仍正确验收 |
| 观测开关拼写错误会被当作 false，悄悄关闭上报 | 只接受明确的 true/false；非法值报错；同时拒绝 NaN 等无效超时 | 配置回归测试通过 |
| 非文本正文、空白正文、畸形 tool_calls 或不合法 token 统计可能被误用 | 底层拒绝非法响应并记录错误；正常 stop 不允许夹带待执行工具 | 协议异常测试通过 |
| 加入重试若覆盖所有错误，容易制造额外调用和观测噪音 | 重试只在显式教学函数中启用；演示 503 有限尝试、401 一次失败 | 离线故障实验和次数断言通过 |
| 新增会话存储可能覆盖并发产生的历史 | SQLite revision 比较，提交冲突明确报错；失败请求不保存半轮历史 | 重开数据库、会话隔离、旧版本覆盖测试通过 |
| 仅检查最终文本会把“没执行工具却碰巧答对”算通过 | 评估同时检查工具参数、实际结果和答案 | 正确文本但无工具证据的反例被拒绝 |

## 内容分级

- [初级](levels/beginner.md)：协议与显式循环。
- [中级](levels/intermediate.md)：输出校验、流式、检索和持久化。
- [高级](levels/advanced.md)：推理模式、评估和综合 Agent。

原理文章保留，三级文档负责学习顺序与实验指导。代码保持普通 Python，同一底层客户端负责真实模型调用与观测，未引入 Agent 框架。

## 当前结论与限制

当前三级教学课程保留 10 个 demo；此前真实模型验收证据见 [验收记录](verification.md)。测试结果不能扩大解释为任意输入、所有模型版本或生产部署均可靠。

仍有明确的教学简化：关键词检索不是语义检索；来源 ID 校验不能证明每句话忠于资料；累计 token 是软预算；观测使用内存队列，停机或断网可能丢数据；会话 ID 隔离不等于身份鉴权。这些限制在对应课程中说明，未伪装成已实现能力。
