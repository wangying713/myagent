# 对外交互与入口适配

此目录按交互方式组织入口。`console` 是通用管理台模板，指定的三课页面通过 HTTP 调用 Go demo；执行流程位于 `apps/demos`。

| 目录 | 职责 | 当前状态 |
| --- | --- | --- |
| `http` | 后台服务 API 的路由、请求校验与响应转换 | 三课接口与健康检查已实现 |
| `console` | 通用管理台前端，通过 HTTP API 使用后台能力 | 官方示例继续 Mock；Demos 下的 Go Agent 示例调用真实 Go 服务 |
| `cli` | 命令行入口与依赖组装 | 预留 |

`apps/config` 加载 Go 启动配置，由入口将各组件所需配置显式传入。前端自己的构建和运行配置放在 `console` 内。
