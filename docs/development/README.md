## Google 三份 Go 文档的关系

Google 官方把三份文档分成不同层级，而不是把所有建议都当作强制规则：

1. **核心规范**：具有规范性，也是最高层级的标准。
2. **具体规范**：具有规范性，解释具体风格决策；与核心规范冲突时，以核心规范为准。
3. **最佳实践**：辅助建议，不具有前两份文档的规范地位，需要结合场景选择。

来源：[Google Go 规范总览](https://google.github.io/styleguide/go/)。

## 中文范围

Google 中文文档是基于官方英文资料的**中文整理译解**。Go 核心规范保留主要论述与规则；Go 具体规范和最佳实践较长，按原文主题提炼规则、理由和例外，省略大量重复代码示例及 Google 内部工具细节。前端资料按本项目需要整理常用语言和页面规则。**这些不是英文文件的逐句全文翻译。**

阅读正文、示例注释和技能说明均使用中文。语言关键字、库名、命令、链接、文件名以及技能格式规定的字段名保留原样。本项目前端具体约定是独立的工程适配，不冒充 Google 原文规则。
