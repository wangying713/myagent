# 多个工具协作

本章已配一个可运行的小 Demo，后面的章节安排用于继续学习和逐步细化。

## 当前可以运行的 Demo

### 先查价格，再计算

Go 只提供 lookup_product 和 multiply 两个工具。模型先查内置商品资料，得到单价后再计算。

管理台打开 **Agent Demos → 多个工具协作**，右侧已有请求参数，可以直接发送，也可以先修改。接口为 `POST /api/agent-demos/multiple-tools`。页面中的原文链接用于核对相关官方资料；项目设计的例子会单独注明。

**怎么看结果：**示例中笔记本每本 23 元，买 4 本应为 92 元；工具结果中能找到价格和资料编号。

当前只有笔记本这个示例商品；查询未知商品时，工具会明确说没有资料。

## 学习目标

让模型在多个能力之间选择，并使用上一步的结果。

## 贯穿案例

“每盒 17 支笔，买 4 盒，一共几支、多少钱？”示例价格表中每盒 23 元。

## 章节安排

### 1. 从一个工具扩到两个

保留乘法，增加本地示例查价；先把两个工具各自的职责讲清楚。

### 2. 选择与分发

根据工具名称分发，分别校验参数；未知工具和未知商品都要明确报错。

### 3. 把步骤串起来

查到单价后再计算，按调用 ID 回填每一个结果；依赖前一步的调用要等到结果可用。

### 4. 看证据，不写死轨迹

检查数据如何进入下一步，不要求模型每次都走完全相同的顺序；先顺序执行。

## 练习方向

准备只算乘法、只查价格、组合计算、未知商品四类题，并画出各自需要的步骤。

## 学会的标准

能根据记录说明 68 支和 92 元的来源，查不到价格时不会编造总价。
