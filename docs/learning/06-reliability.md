# 06：失败、预算与权限

当前三课已实现输入校验、超时取消、预算和观测失败隔离。重试、持久化恢复及有副作用工具留作后续设计。

## 从哪一层失败

| 层次 | 示例 | 当前处理 |
| --- | --- | --- |
| 配置 | 密钥缺失、URL 或开关无效 | 启动前校验，返回中文错误 |
| HTTP 输入 | 错字段、重复字段、空问题、超长正文 | 拒绝，不调用模型 |
| 模型请求 | 网络错误、非成功 HTTP 状态 | 不重试，保留已有步骤并报告失败 |
| 模型协议 | 非 JSON、错误角色、空回答、异常结束 | `invalid_model_response`，不伪造成功 |
| 工具输入 | 未注册名称、无效 JSON、错误数值 | 不执行该函数，回填实际工具错误 |
| 预算 | 下一次调用无额度 | `budget_exceeded`，任务未完成 |
| 取消或超时 | 浏览器取消、请求截止时间 | context 传到底层，停止后续模型和工具 |
| 观测 | OpenObserve 不可用 | 固定提示，不覆盖业务结果；另查入库 |

具体 HTTP 状态和输入限制见 [接口说明](../../apps/interfaces/http/README.md)。失败也可能有已完成的步骤：第二课首轮成功、次轮失败时可以保留首轮回答，但 `completed=false`，不能当作完整两轮成功。

## 四类预算

| 配置 | 默认值 | 约束 |
| --- | --- | --- |
| `AGENT_MAX_MODEL_CALLS` | 5 | 整次运行最多模型请求数 |
| `AGENT_MAX_TOOL_CALLS` | 8 | 工具分发次数，含被拒绝的调用 |
| `AGENT_TOKEN_BUDGET` | 8000 | 下一次模型调用前检查累计已知 token |
| `HTTP_RUN_TIMEOUT` | `120s` | 每次有效请求的运行总截止时间 |
| `DEEPSEEK_TIMEOUT` | `60s` | 每次模型请求的截止时间，受总 context 限制 |

每次模型输出上限固定为 512 token。累计 token 是软预算：本次调用可能越过阈值，随后停止；usage 缺失时不能精确累计，也不能把未知用量当免费。输出上限、输入长度限制和时间预算分别控制不同资源。

工具已执行不代表任务完成。没有下一轮模型额度时，保留工具结果并报告未完成。页面取消也不证明模型服务未处理或未计费，只能停止本程序继续等待和执行后续动作。

## 不自动重试的理由

当前每个模型 span 对应一次实际 HTTP 请求。先让流程可见，再设计有限重试。鉴权失败、参数错误、未知工具重复发送通常无益；超时也不证明远端未处理，重试可能重复计费。

以后只针对明确的临时故障设计有限次数、退避与抖动，每次尝试单独计数和记录。写订单、扣款、发邮件等副作用还需幂等键、执行记录和用户授权；这些不属于当前乘法练习。

## 权限由程序决定

工具描述不能赋予权限。程序只分发注册函数，模型输出名称和参数都按外部输入处理。当前不执行生成源码、不调用 shell、不允许任意文件或数据库操作。

后续若增加文件检索，应定义根目录、路径边界、符号链接策略和文件大小；网页、文件或检索片段里的行动指令不会自动成为用户授权。提示词应与应用校验配合，不能替代校验。

## 离线练习

在项目根目录运行：

```sh
./scripts/go test ./domain/agent ./apps/interfaces/http/api ./infra/openobserve
```

重点读 `TestLoopBudgetsAndProtocolErrors`、`TestRequestDeadlineAndCallerCancellation`、`TestBudgetAndObservabilityFailureIsolation`。分别修改假模型的参数、用量和结束原因，确认失败不会变成成功，也不会执行未注册函数。

通过标准：能从步骤和 trace 指出错误所在层、已经做了什么、为什么停止，以及是否存在未知用量或副作用。
