# Agent 到底是什么

本章已配一个可运行的小 Demo，后面的章节安排用于继续学习和逐步细化。

## 当前可以运行的 Demo

### 一个问题，走两遍

同一个问题先调用普通聊天，再运行带乘法工具的循环。两次都是真实模型请求。

管理台打开 **Agent Demos → Agent 到底是什么**，右侧已有请求参数，可以直接发送，也可以先修改。接口为 `POST /api/agent-demos/overview`。页面中的原文链接用于核对相关官方资料；项目设计的例子会单独注明。

**怎么看结果：**direct 是直接回答，withTools 是工具循环。展开 steps，看看乘法是不是由程序实际执行的。

即使两次答案相同，过程也可能不同；模型没有调用工具时，不把它说成已经执行了工具。

## 学习目标

先看清模型、程序和工具各自做什么，避免把一段聊天当成完整 Agent。

## 贯穿案例

问“17×23 是多少”和“先查单价，再计算总价”，比较两个任务。

## 章节安排

### 1. 模型与程序的分工

模型负责理解、提议下一步和生成回答；Go 程序负责保存状态、检查输入和执行动作。

### 2. 一次任务怎样走完

用户提问 → 请求模型 → 判断是否调用工具 → 执行与回填 → 回答或停止。

### 3. 先固定流程，再增加自主选择

区分普通聊天、固定工作流与由模型选择下一步的循环；简单任务先用简单办法。

## 练习方向

用自己的话画出一次工具调用的过程，在每一步标出谁负责。

## 学会的标准

能解释为什么模型说“我查到了”，不等于程序真的查询过。
