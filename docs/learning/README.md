# Go Agent 开发学习路线

这份路线按 13 章组织。管理台「Agent Demos」按章节提供二级菜单，每章可以阅读文档、打开相关原文、编辑参数、发送请求并查看实际结果。已有「API」页和原来的接口继续保留。

你已经了解部分基础，可以快速回顾“普通聊天、消息历史、工具循环”，然后从**结构化输出**开始。建议按“结构化输出 → 多个工具协作 → 流式回答”继续；如果工具协议还不熟，先回到工具循环一章。

## 课程依据

之前的路线根据项目学习目标和常见 Agent 开发问题整理，没有逐项附上官方来源。现在补充 [DeepSeek 官方示例清单与课程对应关系](deepseek-examples.md)，以后按下面三类依据细化：

- **官方用法**：以 DeepSeek 官方 API 文档、提示库和官方仓库示例为依据，说明模型能接收什么、会返回什么。各项来源见清单。
- **工程补充**：结合本项目 Go 开发规范，补充数据校验、超时取消、执行边界、观测和测试。这些是课程补充，不是 DeepSeek 官方课程。
- **本项目练习**：用买笔记本、查价格、计算总价等简单案例帮助理解。这些案例由本项目设计，不标成官方 demo。

学习顺序按前后依赖安排：先会发请求和保存历史，再学工具、数据与流式处理，最后学资料、运行边界、检查和交付。官方示例清单用于查漏和选课，不代表每个示例都要开发成项目功能。

## 学习方法

每章按同一顺序推进：先用生活中的例子理解问题，再画输入输出和流程，读一份请求或结果样本，最后做练习、检查是否学会。先解释清楚，再运行每章的小案例；章节大纲中尚未包含在小案例里的扩展内容，不代表已实现。

以后逐章细化时，使用“为什么需要 → 一眼看懂的案例 → 分步讲解 → Go 小示例 → 常见错误 → 练习 → 自查”的结构。模型协议、库版本与配置方式在实际讲解或开发时核对，不在大纲中预设某个平台的能力。

- **基础阶段**：能手写一次请求、两轮历史和一次工具调用的消息轨迹。
- **进阶阶段**：能解释数据校验、多工具协作和流式取消如何工作。
- **综合阶段**：能处理失败、使用资料和状态，并用固定题集判断效果。

不安排固定学习天数。每章能回答“输入是什么、谁负责执行、结果怎么检查、什么时候停止”，再进入下一章。
