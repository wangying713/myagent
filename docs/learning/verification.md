# 学习验收方式

本页检查是否学会，不是现有 Agent 功能的运行证明。「Agent 开发」页面只阅读文档，现有业务接口继续在独立「API」页调试。

| 阶段 | 自查方式 | 需要的证据 |
| --- | --- | --- |
| 聊天与历史 | 写出一次请求及两轮消息列表 | 角色、顺序和完整回答 |
| 工具循环 | 画出提出调用、校验、执行、回填、停止 | 调用 ID、参数和真实结果 |
| 结构化与多工具 | 列出正确、错误与缺失信息样本 | 校验规则、依赖关系和失败结果 |
| 流式与边界 | 画正常、中断、取消的状态变化 | 部分内容和完成状态分别表示 |
| 检索与记忆 | 比较有依据、无依据和冲突资料 | 来源、隔离和更新规则 |
| 综合项目 | 先写设计，再决定是否实现 | 范围、流程、固定用例和验收标准 |

后续开始开发时，再执行相应离线测试、类型检查和构建；不拿旧项目测试结果当新功能的验收证据。
