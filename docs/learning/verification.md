## 本机工具链

默认代理及官方二进制下载受到本机网络影响。本次从 Go 官方仓库的 `go1.27.2` 标签源码构建工具链，保存在 Git 忽略的 `.tools/go1.27.2`。`./scripts/go` 选择该工具链并为当前命令设置正确的 `GOROOT`，没有替换系统 Go 或修改全局配置。

真实验收显式复用了本机已有配置中的必要项，写入权限为 0600 的临时配置；未输出、提交或覆盖凭据。验收后临时凭据已清理。应用仍只读取 `-env-file` 指定的配置文件，不自动读取历史配置。
