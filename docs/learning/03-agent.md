# 工具调用与 Agent 循环

本章已配一个可运行的小 Demo，后面的章节安排用于继续学习和逐步细化。

## 当前可以运行的 Demo

### 模型提议，Go 真正计算

模型先提出 multiply 调用，Go 检查参数并计算，再把工具返回的结果交回模型生成回答。

管理台打开 **Agent Demos → 工具调用与循环**，右侧已有请求参数，可以直接发送，也可以先修改。接口为 `POST /api/agent-demos/tools`。页面中的原文链接用于核对相关官方资料；项目设计的例子会单独注明。

**怎么看结果：**steps 里通常能看到 model → tool → model；默认问题的乘法结果是 391。

模型选择调用工具的具体过程以实际返回为准，程序不伪造固定轨迹。

## 学习目标

看懂模型如何提出调用，Go 如何检查、执行和回传结果。

## 贯穿案例

用乘法工具计算每盒 17 支笔、23 盒共多少支。

## 章节安排

### 1. 描述一个工具

列出名称、用途、参数和返回值；描述让模型知道怎么用，程序仍需自己校验。

### 2. 执行与回填

认识工具名、参数 JSON、调用 ID；保存完整 assistant，再用同一个 ID 回传真实结果。

### 3. 让循环停下来

模型回答后结束；遇到取消、超时或调用额度用尽也要停止。

### 4. 工具出错怎么办

区分可回填的参数或业务错误，与应当立即停止的取消、执行故障。

## 练习方向

手写一条“模型 → 工具 → 模型”的消息轨迹，再加一个错误参数的例子。

## 学会的标准

能从真实调用记录证明 391 是工具算出来的，而不是只看最终文字。
