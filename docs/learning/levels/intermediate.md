# 中级：小应用的边界与资料

本页是后续学习路线，Go 版本尚未提供这些 demo、接口或页面。先完成 [初级](beginner.md)，再分阶段提出实现需求。

| 顺序 | 专题 | 先做的练习 | 后续通过标准 |
| --- | --- | --- | --- |
| I01 | [结构化输出](../04-json.md) | 纯 Go 订单解析与业务校验 | 分清语法、类型、必填与业务错误，不将合法 JSON 当授权 |
| I02 | [流式输出](../05-stream-thinking.md) | 假 SSE 服务与重组测试 | 残缺参数不执行，中断不算完成，取消贯通页面和 Go |
| I03 | [最小 RAG](../07-retrieval-memory.md) | 虚构资料、关键词检索、来源 ID | 分开验证检索命中和回答依据，拒绝未提供的引用 |
| I04 | [会话持久化](../07-retrieval-memory.md) | 明确会话模型与存储契约 | 重启恢复、不串会话、失败不保存半轮、版本冲突不覆盖 |

暂不要求向量数据库。先用确定性小测试证明各组件，再增加模型请求与管理台展示。结构化输出、流式、检索和存储不要同时引入。

当前 HTTP、预算、取消和观测可以复用，但不能把旧 Python 脚本的验收结果视为这些 Go 能力已经完成。下一阶段见 [高级路线](advanced.md)。
