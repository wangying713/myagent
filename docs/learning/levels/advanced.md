# 高级：比较、评估与综合项目

本页是后续学习路线，Go 版本尚未实现思考模式、自动批量评估或资料 Agent。先完成前两阶段，再逐项扩展。

| 顺序 | 专题 | 练习方向 | 后续通过标准 |
| --- | --- | --- | --- |
| A01 | [思考模式](../05-stream-thinking.md) | 用“数位和 11、十位比个位大 3”的固定题比较模式 | 验算 74，记录资源消耗，区分思考开关和流式方式 |
| A02 | [固定评估](../08-evaluation.md) | 17×23、0×25、-3×8、12×8 | 同时检查参数、工具实际结果、最终答案和预算，拒绝无工具证据的正确文本 |
| A03 | [只读资料 Agent](../07-retrieval-memory.md) | 模型选择搜索词、应用执行只读搜索并回填 | 引用有来源、无依据时说明、所有步骤可查，查询与返回量受限 |

评估读取业务步骤，入库检查读取 trace，两者分开。保持问题集不变，比较提示词与模型变化，记录成功率、用量、调用数和耗时；不能放宽断言掩盖失败。

综合交付需展示成功、无依据、失败三类运行，并解释边界。向量检索、长期记忆、队列、生产权限与多 Agent 协作仍是进一步需求，不在当前三课里。
