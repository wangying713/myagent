# 综合练习

先理解资料和状态，再组织流程，最后检查效果与交付边界。本页是学习顺序，不是功能开发清单。

- [检索、记忆与会话状态](../07-retrieval-memory.md)：先找资料再回答，并分清资料、历史与长期记忆。
- [任务拆分与工作流](../09-workflows.md)：判断一个任务需要固定步骤、动态循环，还是只要一次请求。
- [日志、执行记录与链路观测](../openobserve.md)：能看出一次任务做了什么、慢在哪里、为什么失败。
- [评估与回归验证](../08-evaluation.md)：用固定题目与证据判断改动是否有效。
- [综合练习与服务交付](../10-delivery.md)：把学过的内容组织成一个边界清楚、可检查的小项目。
