# 初级：看懂模型调用，手写 Agent

本阶段已实现。需要已有 Go 基础：结构体、切片、接口、错误、`defer` 与 `context`。先按 [学习入口](../README.md) 启动服务和管理台。

| 顺序 | 操作 | 阅读重点 | 通过标准 |
| --- | --- | --- | --- |
| B01 [普通聊天](../01-chat.md) | 执行一次，修改“递归”为“函数” | `Service.Chat` → `Client.Chat` → 响应验证 | 找到请求、正文、结束原因、用量和 2 个 span |
| B02 [消息历史](../02-messages.md) | 一次点击运行两轮，核对第二次请求 | 实际 assistant 的保存与完整回传 | 能解释四条历史消息及 3 个 span，不把再次点击当延续会话 |
| B03 [工具循环](../03-agent.md) | 检查参数 17、23，实际结果 391 | 工具描述 → 分发 → `Run` → 回填 | 看到获准工具、配对 ID、下一轮请求和真实最终答案 |

先读流程和协议，再读观测实现。典型第三课为 4 个 span，多个工具或多轮时按真实步骤计数，不固定为 4。

完成三课后，阅读 [失败与预算](../06-reliability.md)，运行 [离线检查](../verification.md)，再按 [OpenObserve](../openobserve.md) 核对入库。

初级完成的标志：能够自己说明“消息 → 模型 → 校验工具 → 执行 → 回填 → 停止”，也能解释取消、无效响应、预算耗尽和观测失败。后续方向见 [中级路线](intermediate.md)。
