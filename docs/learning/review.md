# 学习与设计自查

在理解一章或设计一个练习前，先回答这些问题：

1. 这一步解决什么具体问题？一个普通函数或一次请求是否已经够用？
2. 哪些内容由模型生成，哪些由程序检查和执行？
3. 输入、输出、状态分别是什么？缺失信息如何表达？
4. 工具名称、参数和权限由谁决定？外部资料能不能改变这些权限？
5. 正常完成、失败、取消和超限时各怎样停止？
6. 最终答案有哪些真实结果或资料来源作为证据？
7. 有哪些固定样本可以发现回归？
8. 注释和说明是否不用专业背景也能看懂大概？

当前只有路线与章节大纲。后续逐章细化、配套练习与业务实现由你安排，不根据本清单自动开发。
